Uso no GitHub Codespaces

Para Codespaces, recomendamos criar as credenciais em GitHub → Settings → Secrets and variables → Codespaces, usando OPENAI_API_KEY ou GEMINI_API_KEY. O Forja identifica essas variáveis automaticamente.

Colar uma chave nos campos abaixo salva o valor em settings.json; isso não cria um Secret do Codespaces.
